# 数据库说明

## 一、概览

数据库文件为 `海上风电维检.db`，格式为 SQLite。数据库仅包含两张业务表：

| 表名 | 用途 |
| --- | --- |
| `alarm_records` | 保存风机运行状态和告警记录 |
| `maintenance_records` | 保存维检工单、处理结果、观察时间及简化后的备件情况 |

两张表可通过 `turbine_id` 和 `fault_code` 进行业务关联。数据均为虚构模拟数据，数据库应作为只读资料使用。

## 二、alarm_records

该表共 9 个字段，每行代表一条风机告警记录。

| 字段 | 类型 | 业务含义 |
| --- | --- | --- |
| `alarm_id` | INTEGER | 告警记录编号，主键 |
| `turbine_id` | TEXT | 风机编号，范围为 T01～T09 |
| `turbine_model` | TEXT | 风机型号；同一风机的型号保持一致 |
| `turbine_status` | TEXT | 该条告警记录对应的风机运行状态 |
| `fault_code` | TEXT | 故障代码，可用于检索故障手册或关联工单 |
| `fault_name` | TEXT | 故障名称 |
| `severity` | TEXT | 告警严重程度 |
| `occurred_at` | TEXT | 告警发生时间 |
| `alarm_status` | TEXT | 告警当前状态 |

### 枚举值

`turbine_status`：

- `RUNNING`：运行；
- `STOPPED`：停机；
- `MAINTENANCE`：检修；
- `LIMITED`：限功率或受限运行。

`severity`：

- `INFO`：提示；
- `WARNING`：警告；
- `MAJOR`：重大；
- `CRITICAL`：严重。

`alarm_status`：

- `ACTIVE`：当前未解除；
- `CLEARED`：已解除。

## 三、maintenance_records

该表共 10 个字段，每行代表一张维检工单。

| 字段 | 类型 | 业务含义 |
| --- | --- | --- |
| `work_order_id` | TEXT | 工单编号，主键 |
| `turbine_id` | TEXT | 对应风机编号 |
| `fault_code` | TEXT | 对应故障代码 |
| `priority` | TEXT | 工单优先级 |
| `status` | TEXT | 工单状态 |
| `created_at` | TEXT | 工单创建时间 |
| `resolution_note` | TEXT | 处理措施、处理结果和关闭记录的综合说明；尚无记录时可为空 |
| `observation_minutes` | INTEGER | 处理后的观察时间，单位为分钟；未进入观察阶段时可为空 |
| `required_part` | TEXT | 所需备件名称；不需要备件时为空 |
| `part_available` | INTEGER | 所需备件当前是否可用；不需要备件时为空 |

### 枚举值

`priority`：

- `NORMAL`：普通；
- `HIGH`：高；
- `EMERGENCY`：紧急。

`status`：

- `OPEN`：已创建、待进一步安排；
- `PLANNED`：已计划；
- `IN_PROGRESS`：处理中；
- `COMPLETED`：已完成；
- `CANCELLED`：已取消。

`part_available`：

- `1`：数据库记录显示该备件当前可用；
- `0`：数据库记录显示该备件当前不可用；
- `NULL`：该工单不需要备件或未记录备件需求。

备件字段已经简化，不表示库存数量、预留量、仓库、型号兼容性或现场领用状态。即使 `part_available = 1`，也不能据此推定其他现场作业条件已经满足。

## 四、关联与时间格式

建议将 `turbine_id` 与 `fault_code` 同时作为告警和工单的业务关联条件。仅使用其中一个字段，可能把其他风机或其他故障的工单错误地关联进来。

`occurred_at` 和 `created_at` 均采用文本格式：

```text
YYYY-MM-DD HH:MM:SS
```

所有记录时间均位于 `2026-07-01 00:00:00` 至 `2026-07-20 23:59:59`。SQLite 按该格式进行字符串比较时可保持时间顺序。

## 五、只读要求

本数据库是题目提供的事实资料。请使用只读连接或等效保护措施，避免执行 `INSERT`、`UPDATE`、`DELETE`、`DROP`、`ALTER`、`CREATE` 等修改性操作。
